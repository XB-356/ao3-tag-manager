## 版本二：QQ 空间 / 长文案（约 400 字）

【AO3 标签管家】一个专治"看文踩雷"的浏览器插件

在 AO3 上刷文，最烦的就是翻半天才看到雷点。这个插件帮你把标签和作者的屏蔽、只看规则「记下来」，一次设置，以后自动生效：

❌ **屏蔽**：点标签旁的按钮，或直接右键标签 → 屏蔽。命中就隐藏，眼不见为净
👁 **只看**：只想吃某对 CP / 某个角色？开「只看」，不符合的全折叠
🧹 **快捷屏蔽**：列表里每篇旁边都有「隐藏」「屏蔽」，顺手就清干净
📋 **作品名单**：手动屏蔽过的都记得住，随时能放出来
🌙 **深色适配 + 中文界面**：官方夜间皮肤、自制皮肤都能自动适配；界面文案一键汉化
🔗 **镜像站支持**：官方站上不去也能用，设置里填镜像域名即可

**电脑**装扩展（Chrome / Edge / Brave）；**手机、平板**装油猴脚本（先装暴力猴或篡改猴），功能一样。

规则只存在你的浏览器本地，不联网、不上传、不抓数据。GPL-3.0 开源。

下载地址：https://github.com/XB-356/ao3-tag-manager/releases/latest
（电脑：下载 .zip 解压后到 chrome://extensions/ 加载已解压的扩展程序；手机：直接点 .user.js 安装）

⚠️ 说明：本项目全部由 DeepSeek V4.1 Flash 代工；截图是 mock 测试页面的假数据，不代表作者喜好。扩展默认不含任何屏蔽词，规则怎么配完全看你。

## 发布小提示

- **配图**：直接用仓库 `docs/images/` 下的图，建议挑 `list-blocked.png`（列表效果）+ `context-menu.png`（右键菜单）两张。
- **别发太快**：同人圈对"AI 生成"接受度不一，建议按上面文案里那句说明老实写着，省得被追问。
- **微博**注意把链接放在正文里（部分平台对外链有折叠，可以放在评论区第一条）。
- **安装门槛要写清**：
  - 电脑端扩展需要「开发者模式 + 加载已解压的扩展程序」，不是点一下就装好的那种；
  - 手机端要**先装暴力猴 / 篡改猴**，再点 `.user.js` 安装。
  - 这两句写上，能减少一大半"装了没反应"的提问。
- **镜像站可以顺带当卖点**：官方站抽风的时候，这条能救不少人。
